# Team 67 · Private Network Service Platform (Computer Networks project, Phase 1)

A client resolves `app.team67.test` through our own DNS server, connects over HTTPS to an nginx edge,
and is load-balanced across two Python backends. Three MacBooks on one LAN; no cloud.

```
Client (MS Thejas / Garv Verma)
  ├─ DNS  UDP 53  ───────► Node 1 · Tathagat · dnsmasq
  └─ HTTPS TCP 443 ──────► Node 1 · Tathagat · nginx (TLS terminates, round-robin)
                               ├─ HTTP :3001 ► Node 2 · MS Thejas · Backend A
                               └─ HTTP :3002 ► Node 3 · Garv Verma   · Backend B
```

## How to run the backends

Requirements: macOS with Python 3 (standard library only, nothing to install).

```bash
git clone https://github.com/TathagatHarsh/CN-Phase1-Team67.git
cd CN-Phase1-Team67
BACKEND=A PORT=3001 python3 backend/server.py   # Backend A (MS Thejas's Mac)
BACKEND=B PORT=3002 python3 backend/server.py   # Backend B (Garv Verma's Mac)
```

Each prints `Backend A listening on 0.0.0.0:3001` (or B on 3002) and logs every request with the caller's IP.
It listens on all interfaces so the nginx edge on another Mac can reach it. Stop with Ctrl+C. Quick test on the same Mac:

```bash
curl -si http://127.0.0.1:3001/api/status          # X-Backend: A, {"backend": "A", "status": "ok", ...}
curl -sI http://127.0.0.1:3001/api/cached          # Cache-Control: public, max-age=60 and an ETag
```

## How to run the whole system

Full per-machine steps are in `docs/SETUP.md`; the session procedure we followed is `docs/RUNBOOK.md`. In short, on Node 1 (Tathagat):

```bash
scripts/set-ips.sh <TATHAGAT_IP> <THEJAS_IP> <GARV_IP>              # write the three LAN IPs into the configs
bash certs/make-certs.sh                                             # create the team CA and server certificate (once)
sudo /opt/homebrew/sbin/dnsmasq -C dns/dnsmasq.conf                  # DNS on port 53 (foreground)
sudo nginx -p "$PWD/" -c nginx/team67.conf                           # edge on 80/443
```

On each client Mac: trust `certs/rootCA.pem` (copied from Node 1) in the System keychain and set the Wi-Fi DNS server to Node 1's IP.
Then `curl -i https://app.team67.test/api/status` alternates `x-backend: A` / `B` with no `-k`.

## Endpoints

| Endpoint | Response | Cache-Control |
|---|---|---|
| `GET /` | service, backend, host, "running" | – |
| `GET /api/status` | `{"backend":"A","status":"ok","time":…}` | `no-store` |
| `GET /api/cached` | identical on A and B (same ETag), 304 on `If-None-Match` | `public, max-age=60` |

Every response carries `X-Backend: A` or `X-Backend: B`.

## Security note
`certs/rootCA.key` and `certs/team67.key` never leave Node 1 and are never submitted. Only `rootCA.pem` is
given to client Macs.
